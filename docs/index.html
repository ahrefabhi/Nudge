A tiny creature in your notch that watches over your agents.

A tiny companion that lives in your MacBook's notch and tells you when a Claude Code or Codex session needs you.

Download for macOS View on GitHub
macOS 14+Swift 6.2MIT licenseabout 6 MB

You start a few Claude Code or Codex sessions in iTerm, Terminal and VS Code, switch to something else, and one of them quietly stops to ask for permission. Ten minutes later you notice.

Nudge fixes that. It sits invisibly inside the notch while your agents work. When one needs you, Nudge drops out, the notch opens into a notification, and Open Session takes you straight to the exact terminal tab or editor window. Then Nudge tucks itself away again.

01 · IN THE NOTCH

Invisible until it isn't.

Idle, Nudge is invisible: the notch is just the notch. While agents work, two eyes glance around beside the camera. When something needs you, Nudge drops out.

02 · IT TELLS YOU WHY

The exact command, question or error.

Permission requests show the exact command, questions show their choices, errors show the error, and finished runs show the agent's last reply.

03 · ONE CLICK BACK

Straight to the right tab.

Opens the precise iTerm tab, Terminal tab or VS Code window, and outlines it with a brief focus ring. Several agents waiting become one list, most urgent first.

HOW IT WORKS

Read-only by design. Everything stays on your Mac.

The collector only records. It never answers, approves or blocks anything, prints nothing, and always exits immediately, so it can't slow your agent down or change what it does. The only network request Nudge makes is its update check to GitHub.

Stays out of the way.

Unanswered alerts fold into a small pill. In full screen Nudge shrinks to a thin glow, and it goes quiet while Zoom shares your screen or when you ask it to. Nudge never takes the keyboard from your editor on its own.

Get Nudge.

Free and open source. Requires macOS 14 Sonoma or later and Claude Code in a terminal, VS Code or the Claude app. Codex CLI is optional.

Download latest release Star on GitHub
  1. 1Download Nudge-x.y.z.zip from the latest release and unzip it.
  2. 2Move Nudge.app to your Applications folder.
  3. 3Open Nudge, and let macOS open it once.
  4. 4Follow the short setup. It finds where your agents run and connects to Claude Code and Codex.
Nudge isn't notarized yet. On first launch, click Done, then Open Anyway in Privacy & Security, or run:
xattr -dr com.apple.quarantine /Applications/Nudge.app
Or build from source (Xcode 26, Swift 6.2): 
git clone https://github.com/ahrefabhi/nudge.git
cd nudge
swift run Nudge --demo
